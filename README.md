# Giochi

Giochi per bambini senza pubblicità, senza tracciamento e senza link esterni. Funziona anche offline.

- 🎨 Colora: disegni da colorare con i colori di lato
- 🏀 Basket: striscia il dito per tirare a canestro
- ⚽ Calcio: tira i rigori contro il portiere

Apri: https://budali94.github.io/giochi/
